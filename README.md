## A Collection of Algorithms and Datasets in Machine Learning
Here is collection of all well known algorithms including their datasets. Feel free to edit it.

### Learning with this repo
Every Python notebook is explained step by step in plain English, so you can learn from it even if you are new to machine learning.

- **[Learning path](LEARNING_PATH.md)**: the recommended order, setup, a "what kind of problem do I have?" map, and side-by-side comparison tables of the algorithms.
- **[Glossary](GLOSSARY.md)**: every technical word used in the notebooks, defined in plain English.
- **[Interactive study guide](docs/index.html)**: quizzes, experiments and a progress tracker for every topic (open the file in a browser, or deploy the `docs/` folder to any static host).
- **In each notebook**: a "Before you start" note at the top, an explanation under every step, diagrams for the harder ideas, and "Common mistakes", "Try this yourself" and "Check your understanding" sections at the end.
- **R scripts**: commented in plain English too, step by step.
